# Program icon

polygon-icon-source.png is the user-supplied favicon (2026-09-10).
polygon-icon.svg is a hand-traced vector version with transparent background and radial blue gradient.
polygon-icon.png is its 512 px raster export for the application window.
polygon.ico contains 16, 24, 32, 48, 64, 128 and 256 px images for Windows executable resources.

The SVG is the editable source. Render it with an SVG renderer to regenerate the PNG and ICO; do not enlarge the original favicon.
